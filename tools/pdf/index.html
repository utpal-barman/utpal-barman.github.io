    What this can and cannot do

    Adding text, signatures and cover-ups
    Fully supported, and the result is flattened into the page — it prints and archives like any other PDF.
    Changing text that is already in the file
    A PDF stores placed glyphs, not editable paragraphs, so nothing can reflow it. Retype does the honest version: it covers the old words and puts yours on top, which is what every free editor is actually doing.
    Scanned pages
    A scan is one big image. You can sign it, cover parts of it and type on it, but there is no text underneath to work with.
    Password-protected files
    Opened where the password only restricts permissions. A file that needs a password to read has to be unlocked in your PDF reader first.
